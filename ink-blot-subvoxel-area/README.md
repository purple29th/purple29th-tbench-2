# codimango/ink-blot-subvoxel-area

## Description

Paper QC absorbency test. One ink droplet wicks into filter sheet, file `.inkb` holds the smear. Output true fiber wet area mm2.

The droplet looks larger than it is because capillary bleed plus lens blur spreads darkness. Counting inky pixels fails across batches.

Needs robust paper level and main blot isolation to hit 3 percent.
