# codimango/hydrothermal-sonar-heat-mapping

## Description

ROV sonar mapping of hydrothermal black smokers. File `.svol` holds one bubble plume. Report true plume volume mm3.

Beam side lobes plus scatter make a compact core look like a bloated cloud with wispy tendrils. Bright counting is unstable across dives. Sample differs from hidden cases.

Needs sea floor estimation and main plume isolation to meet 5 percent tolerance.
